# Contact and support

[简体中文](SUPPORT.md) · English · [Product overview](README.en.md)

- Bugs and feature requests: [open a GitHub issue](https://github.com/JinSooo/rynoa/issues/new/choose).
- Private questions, orders, or license support: [kimjinso@qq.com](mailto:kimjinso@qq.com). Include Rynoa in the subject.

Include your Rynoa version, macOS version, Mac model, gesture, steps to reproduce, and expected result. Hide private information in screenshots before sharing them.

GitHub issues are public. Do not include license keys, order numbers, personal email addresses, or complete logs. For order questions, email the order number; you do not need to send bank card details, passwords, or a complete license key.

The current public release is a free beta. No purchase or activation is required, and there is no trial expiry. Paid release plans are on hold. Use the channels above for help with the beta.

Rynoa is an independently developed project, with no guaranteed response time at present. Before reporting an issue, check the [user guide and troubleshooting](HELP.en.md).
